# رُوّاد — ميديا

ملفات المحتوى المنشور لمعهد رُوّاد في دبورية.

- `brand/` الشعار (الأصلي، ونسخة خضراء ونسخة بيضاء بخلفية شفافة). لون الهوية: `#22524E`.
- `posts/<التاريخ>-<الاسم>/` كل منشور بمجلده: الصور أو الفيديو النهائي، و`caption.md` للنص.
- `tools/` سكربتات توليد التصاميم.

الريبو عام لأن Metricool يسحب الصور من روابطه. لذلك: **فقط** تصاميم نهائية منشورة. لا صور طلاب، ولا ملفات خام، ولا أي معلومات خاصة.
